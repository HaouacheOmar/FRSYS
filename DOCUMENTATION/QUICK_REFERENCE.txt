┌──────────────────────────────────────────────────────────────────────────┐
│  🚀 STARTUP COMMANDS                                                     │
└──────────────────────────────────────────────────────────────────────────┘

  ⚡ ADMINISTRATION POST (Start FIRST):
  
     Double-click: START_ADMIN_SERVICES.ps1
     
     Or manually:
     cd ADMINISTRATION_POST
     .\START_ADMIN_SERVICES.ps1

  ⚡ SURVEILLANCE POST (Start AFTER admin is running):
  
     Double-click: START_SURVEILLANCE_CLIENT.ps1
     
     Or manually:
     cd SURVEILLANCE_POST
     .\START_SURVEILLANCE_CLIENT.ps1

  Administration PC:
  ├─ 8000  Django API         [OPEN TO NETWORK] ← Surveillance PCs connect

  Surveillance PCs:
  └─ 3000  React Dev Server   [LOCAL]

┌──────────────────────────────────────────────────────────────────────────┐
│  🔧 FIRST-TIME SETUP                                                     │
└──────────────────────────────────────────────────────────────────────────┘

  1. Administration PC:
  
     □ Install PostgreSQL
     □ Create database: frsys_db
     □ Create user: frsys_user
     □ Copy .env.example → .env (edit settings)
     □ Run: python manage.py migrate
     □ Run: python manage.py createsuperuser
     □ Open firewall port 8000
     
  2. Surveillance PC (each):
  
     □ Install Node.js
     □ Copy .env.example → .env (set Admin PC IP)
     □ Run: npm install
     □ Connect camera

│  ⚠️  TROUBLESHOOTING                                                     │
└──────────────────────────────────────────────────────────────────────────┘

  Problem: "Cannot connect to Administration PC"
  Fix: Check IP in .env, verify firewall, ensure services running

  Problem: "Database connection failed"
  Fix: Check PostgreSQL running, verify credentials in .env

  Problem: "CORS error"
  Fix: Add surveillance PC IP to CORS_ALLOWED_ORIGINS in Django .env

  Problem: "No camera detected"
  Fix: Check camera connection, enable browser permissions
